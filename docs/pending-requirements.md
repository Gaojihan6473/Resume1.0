# 待完成需求清单

记录当前内测反馈中优先级较高、后续需要拆解的产品需求。

## 1. 首页简历解析准确率优化

- 优先级：P0
- 目标：提升用户上传简历后的结构化解析准确率，减少教育、实习、项目、技能、个人总结等模块识别错误。
- 背景：解析结果是用户第一次感知产品可靠性的关键环节，结构错位会直接影响后续编辑、预览和 JD 分析。
- 初步方向：
  - 优化 PDF/DOCX/TXT 文本清洗与断行合并。
  - 强化模块标题、日期、公司、岗位、项目 bullet 的识别规则。
  - 增加解析后的 normalize/repair 层，修复明显错位字段。
  - 收集内测失败样本，按错误类型建立回归案例。

## 2. JD 分析历史记录

- 优先级：P0
- 目标：自动保存 JD 分析记录，避免用户对同一份简历和 JD 反复分析。
- 背景：内测反馈中用户存在重复分析成本，历史记录可以提升复用效率和产品留存。
- 初步方向：
  - 保存每次 JD 分析的输入、结果、时间和状态。
  - 支持查看、重命名、删除、重新分析。
  - 记录简历版本或内容 hash，提示历史结果是否基于旧版简历。
  - 同一份简历 + 同一份 JD 再次分析时，可优先展示历史结果。

## 3. 经历库与 JD 定制简历

- 优先级：P0.5 / 长期核心能力
- 目标：为有多段实习、项目、竞赛、论文等经历的用户建立经历库，并根据 JD 自动推荐或组装最合适的简历内容。
- 背景：多经历用户的痛点不只是分析简历，而是针对不同岗位选择最合适的经历和 bullet。
- 初步方向：
  - 第一阶段：基于当前简历内容，按 JD 推荐保留、弱化或删除的经历。
  - 第二阶段：建立经历库，支持按实习、项目、校园、竞赛、论文等分类沉淀经历。
  - 第三阶段：按 JD 自动挑选经历与 bullet，生成定制版简历草稿并给出选择理由。
